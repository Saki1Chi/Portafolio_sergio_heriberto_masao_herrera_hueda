# Portafolio profesional — Sergio Heriberto Masao Herrera Hueda

Portafolio profesional digital. Sitio estático, sin dependencias ni proceso de
compilación: un `index.html` con el CSS en línea y las evidencias en `assets/img/`.

**Sitio publicado:** https://saki1chi.github.io/Portafolio_sergio_heriberto_masao_herrera_hueda/

## Contenido

Tres sistemas reales documentados, cada uno con título y rol, contexto y problema,
herramientas y tecnologías, evidencia visual o técnica, y resultados medidos:

| Proyecto | Qué es | Evidencia |
|---|---|---|
| **ScanDigit** | Digitalización y OCR de documentos para oficina (FastAPI + React, Docker, red local) | Diagrama de topología de despliegue, diagrama del flujo de captura y OCR, tabla de métricas |
| **Taquería México 85** | Carta digital y pedidos por código QR, funcional sin señal (React + FastAPI + Supabase) | Capturas de portada, tema oscuro, panel de pedidos, mapa y celular |
| **Catálogo de decants** | Catálogo y panel de gestión para perfumería fraccionada (Next.js + Firebase) | Capturas de portada, catálogo de 132 fragancias, ficha individual y celular |

## Estructura

```
index.html          el sitio completo (HTML + CSS en línea + diagramas SVG)
assets/img/         capturas de los proyectos
```

## Detalles técnicos

- **Sin dependencias.** No hay `package.json`, ni bundler, ni framework. Se abre
  directamente en el navegador o se sirve como estático.
- **Tema claro y oscuro** resueltos con variables CSS en los tres estados del
  visor: preferencia del sistema, y elección explícita en cualquiera de los dos
  sentidos.
- **Diagramas en SVG en línea**, con los colores tomados de las mismas variables
  del tema, para que sigan siendo legibles en claro y en oscuro.
- **Tipografías** desde Google Fonts: Archivo (títulos), Source Serif 4 (texto) e
  IBM Plex Mono (datos, etiquetas y diagramas).
